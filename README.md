# 🥗 School Meal Allergen Safety Monitor — AllergenSafe Local

Privacy-conscious, local-first Streamlit platform for screening potential allergen cross-contact pressure in school meal operations using locally supplied ingredient, menu, storage and preparation-workflow records.

Features: 0–100 explainable screening, risk bands, ingredient verification, menu allergen context, storage controls, preparation workflow controls, kitchen comparison, priority queue, signals, scenario lab, CSV upload/export, local visuals and no external APIs.
