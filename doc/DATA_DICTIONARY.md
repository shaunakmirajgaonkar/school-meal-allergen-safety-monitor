# Data Dictionary

Ingredients: ingredient identity, allergen declaration, supplier verification, storage profile and handling context.

Menus: school, meal, allergen declarations, servings and menu status.

Storage: kitchen storage area, segregation, labeling, cleaning readiness, containers, spills and inspection frequency.

Preparation workflows: kitchen step, intensity, cross-contact control, sanitation, utensil/surface separation, changeover discipline, verification and deviations.
